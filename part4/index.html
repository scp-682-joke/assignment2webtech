01 / MOVEMENT STUDY

One More Jump

A small 2D platformer concept about getting movement right: a satisfying jump, a quick dash, and a short level to test them.

2D platformer · Concept
Project details

Start with a single room, a few platforms, and a finish point. Focus on responsive controls before adding art or extra levels.

02 / ATMOSPHERE STUDY

Corridor

A short horror game concept set in an empty corridor. Lighting, sound, and small environmental details tell the story.

Exploration · Concept
Project details

Build one walkable space with an entrance, an exit, and three clues. Experiment with how a familiar place changes when the lights go out.

A 2D game about farming and collecting sugar for ant colony which was colonized by cats.

Puzzle · Concept
Project details

(GameDevClub GameJam IX). You are given 60 seconds to collect as many sugar as possible. Farm more cat mint for your cat bosses using sugar.
